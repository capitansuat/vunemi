If macOS can't verify the download

Vunemi is signed, but this release has not yet been notarized by Apple. macOS may block the disk image. This warning does not prove the file is safe.

Only continue if you downloaded this release from the link above and checked its SHA-256 against the value below.

If you trust the file, choose Done in the warning. Open System Settings › Privacy & Security, scroll down and select Open Anyway. Confirm the next macOS prompt yourself. If unsure, do not open it; contact Support.

Apple's instructions ↗

Install

  1. Open the disk image you downloaded.
  2. Drag Vunemi into the Applications folder.
  3. Open Vunemi from Applications. If macOS says it can't be opened, go to System Settings › Privacy & Security and click Open Anyway.
  4. Choose a model on the first screen. Vunemi suggests one that fits your Mac.

You need

  • A Mac with Apple Silicon (M1 or later)
  • macOS 14 or later
  • Space for a model: the app shows each model's size before downloading

Updating

Download the new disk image and drag Vunemi into Applications again, choosing Replace.
