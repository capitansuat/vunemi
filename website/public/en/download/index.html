What's new · 0.5.1

  • Vunemi 0.5.1 comes out for Mac, Windows and Linux on the same day, from the same code. From now on each new feature comes to all three, apart from what only a Mac has.
  • “Allow just this once” on a card now runs a switched-off tool for that one call, as it says; before, the call failed. The tool stays off afterwards.
  • A path that starts with Documents, Desktop or Downloads now goes to that folder of your home, not to a new folder of that name on the Desktop. A file in a hidden folder of your home stays refused however the home folder is reached.
  • On Windows and Linux, Vunemi now moves files, never over another file; Windows gets dictation and Linux reads answers aloud. The download page says what works on each.

If macOS can't verify the download

Vunemi is signed, but this release has not yet been notarized by Apple. macOS may block the disk image. This warning does not prove the file is safe.

Only continue if you downloaded this release from the link above and checked its SHA-256 against the value below.

If you trust the file, this is how to open it:

  1. Try to open the file. When the warning appears, choose Done.
  2. Open System Settings › Privacy & Security and scroll down to Security.
  3. Next to the message that the file was blocked, click Open Anyway. The button is there only after you have tried to open the file; if it has gone, try once more.
  4. macOS asks again, and may ask for your Mac password or Touch ID. Confirm it yourself.

No Open Anyway button? In the same Security section, check where macOS allows apps from: if only the App Store is selected, choose the App Store and known developers, then try to open the file again. macOS may also block Vunemi itself the first time you open it from Applications; the same steps apply.

If unsure, do not open it; contact Support.

Apple's instructions ↗

Install

  1. Open the disk image you downloaded.
  2. Drag Vunemi into the Applications folder.
  3. Open Vunemi from Applications. If macOS says it can't be opened, go to System Settings › Privacy & Security and click Open Anyway.
  4. Choose a model on the first screen. Vunemi suggests one that fits your Mac.

You need

  • A Mac with Apple Silicon (M1 or later)
  • macOS 14 or later
  • Space for a model: the app shows each model's size before downloading

Updating

From 0.1.8 on, Vunemi tells you when a new version is out and updates itself when you press Update. From an older version, download the new disk image once and drag Vunemi into Applications, choosing Replace.

If macOS asks for your password when Vunemi opens

Vunemi keeps the key to its vault in your Mac's Keychain. Vunemi is not yet signed with an Apple developer identity, so macOS recognises the part that reads this key by its exact code; after an update that changes it, macOS asks for your login password once. Enter it and choose Always Allow: it will not ask again until a later update changes that part. Allow alone lets it through once, and macOS asks again the next time. The prompt is macOS's own; Vunemi never sees your password.

Install

  1. Pick the files for your computer: x64 for most PCs, arm64 for ARM computers. To check, run uname -m: x86_64 means x64, aarch64 means arm64.
  2. Ubuntu and Debian: download the .deb and install it with sudo apt install and its path, for example sudo apt install ./Vunemi-0.5.1-linux-amd64.deb. The packages it needs are installed with it.
  3. Other distributions: download the AppImage, make it executable with chmod +x and open it. Keep it in a folder you can write to, such as ~/Applications, so it can update itself.

The AppImage updates itself: when a new version is out, it says so in the sidebar and in Settings › Updates; press Update. It checks the file against the maintainer's own signature before it uses it. The .deb doesn't update itself, because replacing it would need your administrator password: it tells you about the new version and opens this page, where you download it as before.

You need

  • A 64-bit computer: x64 (most PCs) or ARM (arm64)
  • Ubuntu 22.04 or later, Debian 12 or later, or another distribution with glibc 2.35 or later

On Linux you get chat and tasks with the files on your computer, local models through the built-in engine, Ollama or LM Studio, dictation and voice chat, moving files, and the vault. Voice chat reads answers aloud with espeak-ng, which comes with the app because Linux has no voice that every computer has: it speaks all eleven languages but sounds robotic, and it reads Japanese only in kana, so kanji aren't read properly; without it, you read the answers on screen. Moving files moves only the file you approved and never replaces another file; without it, Vunemi still reads, writes and copies files. The vault needs GNOME Keyring or KWallet; without one it stays locked and everything else works.

Not on Linux yet: controlling apps and the desktop, archive tools, meeting recording, scheduled work, add-ons and the app lock. Shortcuts, Calendar and Apple Mail are Mac apps and stay on the Mac. A few texts still mention the Mac or Finder.

Windows warns you the first time

The installer isn't signed with a paid code-signing certificate, so Microsoft Defender SmartScreen says it doesn't know the publisher. It may warn again when an update installs.

  1. Open the installer.
  2. If Windows says "Windows protected your PC", choose More info.
  3. Check that the app is Vunemi-Setup, then choose Run anyway.

Updates don't depend on SmartScreen: before Vunemi runs a new installer, it checks the file against a signature made with the maintainer's own key, so a file changed on this site or on GitHub can't be installed.

Install

  1. Pick the installer for your computer: x64 for most PCs, arm64 for Windows on ARM. To check, open Settings › System › About and look at System type.
  2. Open it. It installs for your account only and asks for no administrator password.
  3. Vunemi opens when it is done. Afterwards you find it in the Start menu.

Vunemi for Windows updates itself: when a new version is out, it says so in the sidebar and in Settings › Updates; press Update.

You need

  • Windows 11 on an x64 or ARM (arm64) computer
  • About 500 MB for the app, plus room for a model

On Windows you get chat and tasks with the files in the folders you open, local models through the built-in engine, Ollama or LM Studio, dictation and voice chat, moving files, the vault (Windows keeps its key for your account), the Recycle Bin, and updates from inside the app. Dictation turns what you say into text on your computer, without sending it anywhere; voice chat reads the answers aloud with Windows' own voices. Without them, you type and read as before. Moving files moves only the file you approved and never replaces another file; without it, Vunemi still reads, writes and copies files.

Not on Windows yet: controlling apps and the desktop, archive tools, meeting recording, scheduled work, add-ons and app lock. Shortcuts, Calendar and Apple Mail are Mac apps and stay on the Mac.
