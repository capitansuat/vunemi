このバージョンの新機能 · 0.2.0

  • Vunemi は、あなたが作業を続けている間に、アプリのウインドウでバックグラウンド作業ができるようになりました。ボタンを押す、欄を変更する、メニューから選ぶ、スクロールするといった操作です。
  • これまでデスクトップ操作は前面で行われ、クリックや入力の間は待つ必要がありました。バックグラウンドでできない操作は何も送信せず、代わりに前面で操作することもありません。
  • 操作が反映されたかどうか Vunemi が判断できない場合、その操作を繰り返すことはありません。タスクには「結果不明」の印が付き、再起動の後もあなたが確認するまで待ちます。
  • 確認が必要：承認、あなたの返答、確認を待っているタスクを、すべてのセッションから 1 つのリストにまとめます。選ぶとそのタスクがそのまま開きます。
  • この実行の権限：Vunemi がファイルの読み取りやウインドウの確認を求めたとき、毎回承認する代わりに、タスクの残りの間に最大 8 回まで許可できます。いつでも取り消せます。
  • 予約したアプリ作業：あなたが承認した 24 時間以内の最大 4 つの時刻に、開いている書類を Vunemi が変更します。毎回バックアップを残して結果を確認します。
  • キーボードから離れているときだけ実行し、使えなかった時刻はスキップして再試行しません。このバージョンでは、TextEdit の書類に決まった文字を追加します。
  • 選択範囲について質問：回答の一部を選んで質問できます。引用が質問と一緒に送られます。
  • Word、Excel、PowerPoint：これまでアドオンが提供していたのは決まった少数のツールだけでした。
  • 今は、プログラムが対応しているすべての機能を Vunemi が使えます。既存のブックの変更、シートやピボットテーブルの追加、混在した書式を保ったままの Word 書類の変更、スライドのレイアウト調整ができます。
  • 新しい書類や表には読みやすい表が入ります。
  • はっきりした見出し、ゆとりのある行、精度を保った揃った数字が付き、推測した通貨は付けません。依頼すれば、Vunemi は隣にバックアップを置いてから Office ファイルそのものを変更します。依頼しなければ新しいファイルを作ります。
  • ファイル：ファイルを移動するときはバックアップを残し、すでにあるファイルを上書きすることはありません。
  • 金庫に専用のヘルパーが付きました。このアップデートの後、macOS がログインパスワードを一度求めることがあります。「常に許可」を選んでください。依頼がどれだけうまく実行されるかは、引き続きモデルによります。
!

macOS でダウンロードを検証できないと表示された場合

Vunemi は署名されていますが、このバージョンはまだ Apple の公証を受けていません。そのため macOS がディスクイメージをブロックする場合があります。この警告はファイルの安全性を証明するものではありません。

上のリンクからこのバージョンをダウンロードし、SHA-256 が下の値と一致することを確認した場合のみ続行してください。

ファイルを信頼できる場合は、次の手順で開きます。

  1. ファイルを開いてみます。警告が表示されたら「完了」を選びます。
  2. 「システム設定」›「プライバシーとセキュリティ」を開き、下へスクロールして「セキュリティ」の項目を表示します。
  3. ファイルがブロックされたというメッセージの横にある「このまま開く」をクリックします。このボタンは、ファイルを開こうとした後にだけ表示されます。消えている場合は、もう一度開いてみてください。
  4. macOS がもう一度確認し、Mac のパスワードまたは Touch ID を求めることがあります。ご自身で確認してください。

「このまま開く」ボタンがない場合は、同じ「セキュリティ」の項目で、macOS がどこからのアプリを許可しているかを確認してください。App Store だけが選ばれている場合は、App Store と既知のデベロッパを選び、もう一度ファイルを開いてみてください。「アプリケーション」から Vunemi を初めて開くときにも、macOS がブロックすることがあります。手順は同じです。

不安がある場合は開かずにサポートへご連絡ください。

インストール

  1. ダウンロードしたディスクイメージを開きます。
  2. Vunemi を「アプリケーション」フォルダにドラッグします。
  3. 「アプリケーション」から Vunemi を開きます。開けないと表示された場合は、「システム設定 › プライバシーとセキュリティ」で「このまま開く」をクリックします。
  4. 最初の画面でモデルを選びます。Vunemi が Mac に合うものを提案します。

必要なもの

  • Apple シリコン搭載の Mac（M1 以降）
  • macOS 14 以降
  • モデル用の空き容量（ダウンロード前にアプリが各モデルのサイズを表示します）

アップデート

0.1.8 以降は、新しいバージョンが出ると Vunemi がお知らせし、「アップデート」を押すと自動で更新します。それより前のバージョンからは、新しいディスクイメージを一度ダウンロードし、Vunemi を「アプリケーション」にドラッグして「置き換える」を選んでください。

Vunemi を開くときに macOS がパスワードを求める場合

Vunemi は金庫の鍵を Mac のキーチェーンに保存しています。Vunemi はまだ Apple のデベロッパ ID で署名されていないため、macOS はこの鍵を読み取る部品をコードそのもので識別します。その部品が変わるアップデートの後、macOS はログインパスワードを一度だけ求めます。パスワードを入力して「常に許可」を選ぶと、次にその部品が変わるアップデートまで再び求められることはありません。「許可」だけを選ぶと今回限りとなり、次回の起動時にまた求められます。この確認は macOS によるもので、Vunemi がパスワードを見ることはありません。
