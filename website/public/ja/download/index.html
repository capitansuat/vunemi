このバージョンの新機能 · 0.5.1

  • Vunemi 0.5.1 は Mac、Windows、Linux 向けに同じ日に、同じコードから公開されます。今後、新しい機能は Mac にしかないものを除き、3 つすべてに届きます。
  • カードの「今回だけ許可」は、オフにしたツールをその 1 回の呼び出しだけ、表示どおり実行するようになりました。以前は呼び出しが失敗していました。ツールはその後もオフのままです。
  • Documents、Desktop、Downloads で始まるパスは、デスクトップに同じ名前の新しいフォルダーを作らず、ホームフォルダーのそのフォルダーを指すようになりました。ホームフォルダー内の隠しフォルダーのファイルは、どのようにたどっても拒否されます。
  • Windows と Linux でファイルを移動できるようになりました。ほかのファイルを上書きすることはありません。Windows では音声入力、Linux では回答の読み上げが使えます。どこで何が使えるかはダウンロードページにあります。
!

macOS でダウンロードを検証できないと表示された場合

Vunemi は署名されていますが、このバージョンはまだ Apple の公証を受けていません。そのため macOS がディスクイメージをブロックする場合があります。この警告はファイルの安全性を証明するものではありません。

上のリンクからこのバージョンをダウンロードし、SHA-256 が下の値と一致することを確認した場合のみ続行してください。

ファイルを信頼できる場合は、次の手順で開きます。

  1. ファイルを開いてみます。警告が表示されたら「完了」を選びます。
  2. 「システム設定」›「プライバシーとセキュリティ」を開き、下へスクロールして「セキュリティ」の項目を表示します。
  3. ファイルがブロックされたというメッセージの横にある「このまま開く」をクリックします。このボタンは、ファイルを開こうとした後にだけ表示されます。消えている場合は、もう一度開いてみてください。
  4. macOS がもう一度確認し、Mac のパスワードまたは Touch ID を求めることがあります。ご自身で確認してください。

「このまま開く」ボタンがない場合は、同じ「セキュリティ」の項目で、macOS がどこからのアプリを許可しているかを確認してください。App Store だけが選ばれている場合は、App Store と既知のデベロッパを選び、もう一度ファイルを開いてみてください。「アプリケーション」から Vunemi を初めて開くときにも、macOS がブロックすることがあります。手順は同じです。

不安がある場合は開かずにサポートへご連絡ください。

インストール

  1. ダウンロードしたディスクイメージを開きます。
  2. Vunemi を「アプリケーション」フォルダにドラッグします。
  3. 「アプリケーション」から Vunemi を開きます。開けないと表示された場合は、「システム設定 › プライバシーとセキュリティ」で「このまま開く」をクリックします。
  4. 最初の画面でモデルを選びます。Vunemi が Mac に合うものを提案します。

必要なもの

  • Apple シリコン搭載の Mac（M1 以降）
  • macOS 14 以降
  • モデル用の空き容量（ダウンロード前にアプリが各モデルのサイズを表示します）

アップデート

0.1.8 以降は、新しいバージョンが出ると Vunemi がお知らせし、「アップデート」を押すと自動で更新します。それより前のバージョンからは、新しいディスクイメージを一度ダウンロードし、Vunemi を「アプリケーション」にドラッグして「置き換える」を選んでください。

Vunemi を開くときに macOS がパスワードを求める場合

Vunemi は金庫の鍵を Mac のキーチェーンに保存しています。Vunemi はまだ Apple のデベロッパ ID で署名されていないため、macOS はこの鍵を読み取る部品をコードそのもので識別します。その部品が変わるアップデートの後、macOS はログインパスワードを一度だけ求めます。パスワードを入力して「常に許可」を選ぶと、次にその部品が変わるアップデートまで再び求められることはありません。「許可」だけを選ぶと今回限りとなり、次回の起動時にまた求められます。この確認は macOS によるもので、Vunemi がパスワードを見ることはありません。

インストール

  1. お使いのコンピュータに合うファイルを選びます。ほとんどの PC は x64、ARM のコンピュータは arm64 です。確かめるには uname -m を実行します。x86_64 なら x64、aarch64 なら arm64 です。
  2. Ubuntu と Debian：.deb をダウンロードし、sudo apt install にファイルのパスを付けてインストールします（例：sudo apt install ./Vunemi-0.5.1-linux-amd64.deb）。必要なパッケージも一緒にインストールされます。
  3. そのほかのディストリビューション：AppImage をダウンロードし、chmod +x で実行可能にしてから開きます。自動でアップデートできるように、~/Applications など書き込めるフォルダーに置いてください。

AppImage は自動でアップデートします。新しいバージョンが出るとサイドバーと「設定」›「アップデート」に表示されるので、「アップデート」を押します。ファイルを使う前に、開発者自身の署名で確認します。.deb は自動ではアップデートしません。置き換えるには管理者パスワードが必要になるためです。新しいバージョンを知らせてこのページを開くので、これまでどおりここからダウンロードしてください。

必要なもの

  • 64 ビットのコンピュータ：x64（ほとんどの PC）または ARM（arm64）
  • Ubuntu 22.04 以降、Debian 12 以降、または glibc 2.35 以降のほかのディストリビューション

Linux では、チャットとコンピュータ上のファイルを使うタスク、内蔵エンジン・Ollama・LM Studio によるローカルモデル、音声入力とボイスチャット、ファイルの移動、金庫を使えます。ボイスチャットは espeak-ng で回答を読み上げます。Linux にはどのコンピュータにもある音声がないため、アプリに同梱しています。11 の言語すべてを話せますが、声はロボットのようで、日本語はかなでしか読めないため漢字は正しく読まれません。読み上げがなくても、回答は画面で読めます。ファイルの移動は、あなたが承認したファイルだけを動かし、ほかのファイルを置き換えることはありません。移動がなくても、Vunemi はファイルの読み書きとコピーができます。金庫には GNOME Keyring か KWallet が必要です。どちらもない場合、金庫はロックされたままですが、ほかの機能はすべて使えます。

Linux ではまだ使えないもの：アプリやデスクトップの操作、アーカイブツール、会議の録音、スケジュールされた作業、アドオン、アプリのロック。ショートカット、カレンダー、Apple Mail は Mac のアプリなので Mac だけです。一部の文章にはまだ Mac や Finder が出てきます。

最初は Windows が警告を表示します

インストーラーは有料のコード署名証明書で署名されていないため、Microsoft Defender SmartScreen は発行元を確認できないと表示します。アップデートのインストール時にも再び表示されることがあります。

  1. インストーラーを開きます。
  2. 「Windows によって PC が保護されました」と表示されたら、「詳細情報」を選びます。
  3. アプリが Vunemi-Setup であることを確かめてから、「実行」を選びます。

アップデートは SmartScreen に頼りません。Vunemi は新しいインストーラーを実行する前に、開発者自身の鍵で作った署名でファイルを確かめます。このサイトや GitHub で書き換えられたファイルはインストールされません。

インストール

  1. パソコンに合ったインストーラーを選びます。ほとんどのパソコンは x64、ARM 版 Windows は arm64 です。確かめるには「設定」›「システム」›「バージョン情報」を開き、「システムの種類」を見ます。
  2. 開きます。あなたのアカウントにだけインストールされ、管理者のパスワードは求められません。
  3. 終わると Vunemi が開きます。その後はスタートメニューにあります。

Windows 版 Vunemi は自動でアップデートします。新しいバージョンが出るとサイドバーと「設定」›「アップデート」に表示されるので、「アップデート」を押します。

必要なもの

  • x64 または ARM(arm64)のパソコンで動く Windows 11
  • アプリ用に約 500 MB と、モデル用の空き容量

Windows では、開いたフォルダーのファイルを使ったチャットとタスク、内蔵エンジン・Ollama・LM Studio によるローカルモデル、音声入力とボイスチャット、ファイルの移動、保管庫(鍵は Windows があなたのアカウント用に保管します)、ごみ箱、アプリ内からのアップデートが使えます。音声入力は、話した内容をどこにも送らずにコンピュータ上で文字にします。ボイスチャットは Windows 自身の音声で回答を読み上げます。これらがなくても、これまでどおり入力して読めます。ファイルの移動は、あなたが承認したファイルだけを動かし、ほかのファイルを置き換えることはありません。移動がなくても、Vunemi はファイルの読み書きとコピーができます。

Windows ではまだ使えないもの:アプリやデスクトップの操作、アーカイブツール、会議の録音、スケジュールされた作業、アドオン、アプリのロック。ショートカット、カレンダー、Apple Mail は Mac のアプリなので Mac だけです。
