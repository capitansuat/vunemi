Что нового в этой версии · 0.5.0

  • Новое: когда беседа без темы что-то ищет в интернете, Vunemi собирает ответ, прочитанные адреса и сохранённые пункты во временной теме и спрашивает, оставить её под названием, которое можно изменить, или удалить.
  • Это сделано потому, что при долгом поиске память модели заполнялась целыми страницами и найденное терялось. Теперь страницы читаются по основному содержимому, а старые шаги сокращаются. Если удалить, ничего не останется; ответ останется в беседе.
  • Меньше карточек в интернете: обычные ссылки и поле поиска сайта считаются чтением. «Одобрить всё» покрывает один сайт до конца задачи, а доверенный сайт требует одного одобрения на задачу. Формы, отправка и удаление по-прежнему спрашивают.
  • Тема предлагается, только если запрос ближе к ней, чем к повседневным запросам, а скрипты страницы больше не могут выдать форму, отправляющую данные, за поиск.

Если macOS не может проверить загрузку

Vunemi подписан, но эта версия ещё не прошла нотариальное заверение Apple. macOS может заблокировать образ диска. Предупреждение не доказывает, что файл безопасен.

Продолжайте, только если загрузили эту версию по ссылке выше и сверили SHA-256 со значением ниже.

Если доверяете файлу, откройте его так:

  1. Попробуйте открыть файл. Когда появится предупреждение, нажмите «Готово».
  2. Откройте Системные настройки › Конфиденциальность и безопасность и прокрутите вниз до раздела «Безопасность».
  3. Рядом с сообщением о том, что файл заблокирован, нажмите «Всё равно открыть». Кнопка появляется только после попытки открыть файл; если она исчезла, попробуйте ещё раз.
  4. macOS спросит ещё раз и может запросить пароль Mac или Touch ID. Подтвердите самостоятельно.

Нет кнопки «Всё равно открыть»? В том же разделе «Безопасность» проверьте, откуда macOS разрешает приложения: если выбран только App Store, выберите App Store и известных разработчиков и снова попробуйте открыть файл. macOS может заблокировать и сам Vunemi при первом запуске из папки «Программы»; шаги те же.

Если сомневаетесь, не открывайте файл и свяжитесь с поддержкой.

Инструкция Apple ↗

Установка

  1. Откройте скачанный образ диска.
  2. Перетащите Vunemi в папку «Программы».
  3. Откройте Vunemi из папки «Программы». Если macOS сообщит, что приложение нельзя открыть, перейдите в «Системные настройки › Конфиденциальность и безопасность» и нажмите «Всё равно открыть».
  4. Выберите модель на первом экране. Vunemi предложит подходящую для вашего Mac.

Что понадобится

  • Mac с Apple Silicon (M1 или новее)
  • macOS 14 или новее
  • Место для модели: приложение показывает размер каждой модели до загрузки

Обновление

Начиная с 0.1.8, Vunemi сообщает о выходе новой версии и обновляется, когда вы нажимаете «Обновить». Со старой версии один раз скачайте новый образ диска и перетащите Vunemi в «Программы», выбрав «Заменить».

Если при запуске Vunemi macOS спрашивает пароль

Vunemi хранит ключ от своего сейфа в Связке ключей вашего Mac. Vunemi пока не подписан удостоверением разработчика Apple, поэтому macOS узнаёт часть, которая читает этот ключ, по её точному коду; после обновления, которое её меняет, macOS один раз спрашивает ваш пароль входа. Введите его и выберите «Всегда разрешать»: вопрос повторится, только когда очередное обновление изменит эту часть. Если выбрать «Разрешить», доступ даётся один раз, и при следующем запуске macOS спросит снова. Этот запрос показывает macOS; Vunemi не видит ваш пароль.

Установка

  1. Выберите файлы для своего компьютера: x64 для большинства ПК, arm64 для компьютеров ARM. Чтобы проверить, выполните uname -m: x86_64 означает x64, aarch64 означает arm64.
  2. Ubuntu и Debian: скачайте .deb и установите его командой sudo apt install с путём к файлу, например sudo apt install ./Vunemi-0.2.6-linux-amd64.deb. Нужные пакеты установятся вместе с ним.
  3. Другие дистрибутивы: скачайте AppImage, сделайте его исполняемым командой chmod +x и откройте. Держите его в папке, куда у вас есть право записи, например ~/Applications, чтобы он мог обновляться сам.

AppImage обновляется сам: когда выходит новая версия, он сообщает об этом на боковой панели и в «Настройки» › «Обновления»; нажмите «Обновить». Перед использованием он сверяет файл с подписью самого разработчика. Пакет .deb сам не обновляется, потому что для его замены нужен ваш пароль администратора: он сообщает о новой версии и открывает эту страницу, где вы скачиваете её, как раньше.

Что нужно

  • 64-битный компьютер: x64 (большинство ПК) или ARM (arm64)
  • Ubuntu 22.04 или новее, Debian 12 или новее либо другой дистрибутив с glibc 2.35 или новее

В Linux есть чат и задачи с файлами на вашем компьютере, локальные модели через встроенный движок, Ollama или LM Studio, диктовка и сейф. Сейфу нужен GNOME Keyring или KWallet; без них он остаётся заблокированным, а всё остальное работает.

Пока нет в Linux: управление приложениями и рабочим столом, перемещение файлов, работа с архивами, чтение ответов вслух, запись встреч, задачи по расписанию, дополнения и блокировка приложения. Быстрые команды, Календарь и Apple Mail — приложения Mac, они остаются на Mac. Некоторые тексты ещё упоминают Mac или Finder.

В первый раз Windows предупредит вас

Установщик не подписан платным сертификатом подписи кода, поэтому Microsoft Defender SmartScreen сообщает, что не знает издателя. При установке обновления предупреждение может появиться снова.

  1. Откройте установщик.
  2. Если Windows пишет «Система Windows защитила ваш компьютер», выберите «Подробнее».
  3. Проверьте, что приложение называется Vunemi-Setup, и выберите «Выполнить в любом случае».

Обновления не зависят от SmartScreen: прежде чем запустить новый установщик, Vunemi проверяет файл по подписи, сделанной собственным ключом разработчика, поэтому файл, изменённый на этом сайте или на GitHub, установить нельзя.

Установка

  1. Выберите установщик для своего компьютера: x64 для большинства ПК, arm64 для Windows на ARM. Чтобы проверить, откройте «Параметры» › «Система» › «О системе» и посмотрите «Тип системы».
  2. Откройте его. Он устанавливает приложение только для вашей учётной записи и не просит пароль администратора.
  3. После установки Vunemi откроется. Потом его можно найти в меню «Пуск».

Vunemi для Windows обновляется сам: когда выходит новая версия, он сообщает об этом на боковой панели и в «Настройки» › «Обновления»; нажмите «Обновить».

Вам нужно

  • Windows 11 на компьютере x64 или ARM (arm64)
  • Около 500 МБ для приложения и место для модели

В Windows есть чат и задачи с файлами в открытых вами папках, локальные модели через встроенный движок, Ollama или LM Studio, хранилище (его ключ Windows хранит для вашей учётной записи), корзина и обновления из приложения.

Пока нет в Windows: управление приложениями и рабочим столом, перемещение файлов, работа с архивами, диктовка, голосовой чат и чтение ответов вслух, запись встреч, задачи по расписанию, дополнения и блокировка приложения. Быстрые команды, Календарь и Apple Mail — приложения Mac, они остаются на Mac.
