Mac 上的个人助理

帮你处理日常事务，AI 在你的 Mac 上运行。

Vunemi 帮你处理邮件、文件、日历和网页。修改内容前，它会先征求你的同意。AI 模型在你的 Mac 上运行；Vunemi 不会把对话或文档上传到自己的云端处理。

Vunemi 绝不会做的事

无论权限级别如何。遇到这些步骤，它都会停下来交给你。

  • 输入密码、银行卡号、账号或证件号码
  • 破解验证码（CAPTCHA）
  • 支付任何款项
  • 永久删除任何内容

三步开始使用

  1. 下载并安装

    打开磁盘映像，把 Vunemi 拖到“应用程序”文件夹。

  2. 选择模型

    Vunemi 会推荐适合你 Mac 内存的模型并自动下载。已经在用 LM Studio 或 Ollama？直接连接即可。

  3. 只打开需要的

    在“设置 › 连接”中，只打开你希望 Vunemi 使用的项目。

须知

  • 效果取决于模型和你的 Mac。小模型在复杂任务上更容易出错。
  • 适用于搭载 Apple 芯片、运行 macOS 14 或更高版本的 Mac。
  • 任务（包括定时任务）只在 Vunemi 打开时运行。
  • 应用已签名，但尚未经过 Apple 公证。首次打开时，你可能需要在“系统设置 › 隐私与安全性”中点按“仍要打开”。

为什么是 Vunemi？

小事会越积越多。

一封待回复的邮件，一份找不到的文件，一张排满的日历。Vunemi 正是为这些时刻而做：它分担琐事，操作前先询问，并在你的 Mac 上运行 AI。

开源，共同打造

Vunemi 的代码以 GPL-3.0 许可证发布在 GitHub 上。任何人都可以阅读代码、核实它在做什么，并帮助改进。
