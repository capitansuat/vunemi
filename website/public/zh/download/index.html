本次更新 · 0.5.0

  • 新功能：没有主题的对话在网上查找时，Vunemi 会把回答、读过的地址和保留的条目收集到一个临时主题里，然后问你是保留它（名称可改）还是删除它。

Apple 官方说明 ↗

安装

  1. 打开下载好的磁盘映像。
  2. 把 Vunemi 拖到“应用程序”文件夹。
  3. 从“应用程序”打开 Vunemi。如果 macOS 提示无法打开，请前往“系统设置 › 隐私与安全性”，点按“仍要打开”。
  4. 在第一个画面选择模型。Vunemi 会推荐适合你 Mac 的模型。

所需条件

  • 搭载 Apple 芯片的 Mac（M1 或更新）
  • macOS 14 或更高版本
  • 存放模型的空间：下载前应用会显示每个模型的大小

更新

从 0.1.8 起，新版本发布时 Vunemi 会通知你，点按“更新”即可自动更新。如果你使用的是更早的版本，请再下载一次新的磁盘映像，将 Vunemi 拖到“应用程序”并选择“替换”。

如果打开 Vunemi 时 macOS 要求输入密码

Vunemi 把保险库的密钥保存在 Mac 的钥匙串中。Vunemi 尚未使用 Apple 开发者身份签名，因此 macOS 只能通过确切的代码来识别读取这把密钥的组件；在某次更新改动了该组件之后，macOS 会询问一次你的登录密码。输入密码并选择“始终允许”：在以后的更新再次改动该组件之前，它不会再问。如果只选择“允许”，仅本次有效，下次打开时 macOS 还会再问。这个提示来自 macOS；Vunemi 看不到你的密码。

安装

  1. 选择适合你电脑的文件：大多数 PC 用 x64，ARM 电脑用 arm64。要确认的话，运行 uname -m：x86_64 表示 x64，aarch64 表示 arm64。
  2. Ubuntu 和 Debian：下载 .deb，用 sudo apt install 加上文件路径来安装，例如 sudo apt install ./Vunemi-0.5.0-linux-amd64.deb。所需的软件包会一起安装。
  3. 其他发行版：下载 AppImage，用 chmod +x 设为可执行，然后打开。把它放在你能写入的文件夹里，例如 ~/Applications，这样它才能自己更新。

AppImage 会自己更新：有新版本时，它会在侧边栏和“设置”›“更新”里告诉你；点“更新”即可。使用文件之前，它会用开发者自己的签名核对。.deb 不会自己更新，因为替换它需要你的管理员密码：它会告诉你有新版本并打开本页，你可以像以前一样在这里下载。

你需要

  • 一台 64 位电脑：x64（大多数 PC）或 ARM（arm64）
  • Ubuntu 22.04 或更高版本、Debian 12 或更高版本，或其他使用 glibc 2.35 或更高版本的发行版

在 Linux 上可以使用聊天和处理电脑上文件的任务，通过内置引擎、Ollama 或 LM Studio 使用本地模型，还有听写和语音聊天、移动文件以及保险库。语音聊天用 espeak-ng 朗读回答；因为 Linux 没有每台电脑都自带的语音，它随应用一起提供。它能说全部十一种语言，但声音像机器人，日语只按假名朗读，汉字读不准；没有它时，你在屏幕上阅读回答。移动文件只移动你批准的文件，绝不覆盖其他文件；没有它，Vunemi 依然可以读取、写入和复制文件。保险库需要 GNOME Keyring 或 KWallet；没有它们时保险库保持锁定，其他功能照常可用。

Linux 上暂时没有：控制应用和桌面、压缩包工具、会议录音、定时任务、附加组件和应用锁。快捷指令、日历和 Apple Mail 是 Mac 应用，只在 Mac 上。有些文字仍提到 Mac 或访达。

第一次 Windows 会提醒你

安装程序没有用付费的代码签名证书签名,所以 Microsoft Defender SmartScreen 会说它不认识发布者。安装更新时也可能再次提醒。

  1. 打开安装程序。
  2. 如果 Windows 显示“Windows 已保护你的电脑”,选择“更多信息”。
  3. 确认应用是 Vunemi-Setup,然后选择“仍要运行”。

更新不依赖 SmartScreen:Vunemi 在运行新的安装程序之前,会用开发者自己的密钥所做的签名检查文件,所以在本网站或 GitHub 上被改动的文件无法安装。

安装

  1. 选择适合你电脑的安装程序:大多数电脑选 x64,ARM 版 Windows 选 arm64。要查看,打开“设置”›“系统”›“系统信息”,看“系统类型”。
  2. 打开它。它只为你的账户安装,不需要管理员密码。
  3. 安装完成后 Vunemi 会打开。之后可以在开始菜单里找到它。

Windows 版 Vunemi 会自己更新:有新版本时,它会在侧边栏和“设置”›“更新”里告诉你;点“更新”即可。

你需要

  • x64 或 ARM(arm64)电脑上的 Windows 11
  • 应用约需 500 MB,另外还要给模型留空间

在 Windows 上,你可以用打开的文件夹里的文件聊天和执行任务,通过内置引擎、Ollama 或 LM Studio 使用本地模型,使用听写和语音聊天、移动文件、保险库(Windows 为你的账户保管它的密钥)和回收站,并在应用内更新。听写在你的电脑上把你说的话变成文字,不发送到任何地方;语音聊天用 Windows 自带的语音朗读回答。没有它们,你照常打字和阅读。移动文件只移动你批准的文件,绝不覆盖其他文件;没有它,Vunemi 依然可以读取、写入和复制文件。

Windows 上暂时没有:控制应用和桌面、压缩包工具、会议录音、定时任务、附加组件和应用锁。快捷指令、日历和 Apple Mail 是 Mac 应用,只在 Mac 上。
