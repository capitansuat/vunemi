Mac 上的个人助理

Vunemi 的全部功能

详细了解 Vunemi 0.1.6：如何与它协作、它能连接什么，以及你如何保持掌控。

轻松处理邮件

找出等你回复的邮件，总结往来内容，并起草回复。支持 Mac 上“邮件”App 中的账户、Gmail、Outlook 和其他 IMAP 账户，未经你同意绝不发送。

安排好一天

读取你的日历和提醒事项，包括添加到 Mac 上的 Google 或 Outlook 日历，经你同意后添加日程或待办。

我明天的日程有哪些？

查找和整理文件

在桌面、文稿和下载文件夹中搜索，阅读文档，经你同意后移动或重命名文件。每项改动都可以撤销。

找出桌面上的发票，放到一个文件夹里。

上网查资料

在 Vunemi 内置的浏览器中打开网页，与你自己的浏览器分开。它会阅读、比较、填写表单，你随时可以点“接管控制”。

比较这三家博物馆的开放时间。

使用 Mac 应用

可配合备忘录、Excel、Word、PowerPoint、访达、通讯录、信息等应用工作，无需在屏幕上到处点击。每个应用都有单独的开关。

汇总这张 Excel 表里的支出。

说话代替打字

用在 Mac 上运行的语音模型听写：你说话，文字就会出现。能用语音回答的语音对话将在之后的版本中推出。

给我看看今天的会议。

定时任务

让它每天早上做一份汇总，或每周检查一次。定时任务在 Vunemi 打开时运行，绝不会发送、删除或付款。

每天早上 9 点汇总我的日历。

给它看图片

附上截图或照片。能看懂图片的模型会描述内容；换成其他模型，Vunemi 也能在你的 Mac 上读出图中的文字。

记住你说过的话

告诉它你喜欢的工作方式，或谁是谁；经你同意后，它会用你的原话记下来。每个回答都会显示它收到了哪些笔记；你可以在设置中编辑或删除。

记住：我要 PDF 格式的报告。

录制会议

点击“录制”以采集麦克风和 Mac 声音。Vunemi 在此 Mac 上生成文字记录和摘要；摘要完成后将音频移入废纸篓。需要 macOS 14.2 或更高版本。

与 Vunemi 协作

先看计划

遇到需要多个步骤的任务，Vunemi 可以先给出计划。你可以开始执行、编辑步骤或取消。

确认卡片

每项改动都会以卡片形式呈现，写明会发生什么、在哪里、涉及谁。

排队或插队

任务运行时可以输入下一个请求。它会排队等候，你也可以中断当前任务，让它马上执行。

紧急停止

按 ⌘⇧Esc 可停止正在运行的任务，即使 Vunemi 已锁定也有效。

从中断处继续

如果 Vunemi 在任务中途关闭，它会告诉你进行到哪一步并提议继续；遇到会改动或发送内容的步骤，都会先问你。

项目

把一个文件夹设为项目：Vunemi 会把这项工作的文件放在那里，每项改动都可以撤销。

记忆

来自你原话的笔记，只有经你同意才会保存。每个任务只会收到与之相关的笔记，回答会说明收到了几条。

连接

每个连接在你打开之前都是关闭的。关闭的连接对模型不可见，其工具根本无法调用。很多连接对“读取”和“修改”设有单独的开关。

文件

只限你的桌面、文稿和下载文件夹。

开关: 读取 · 写入（可撤销；删除的内容进入废纸篓）· 转换（图片、音频、文档）

浏览器

Vunemi 窗口中的浏览器，与你的 Chrome 或 Safari 分开。登录一次即可保持登录；随时可以接管控制。

开关: 读取网页 · 点击和输入

邮件

Mac 上“邮件”App 中的账户（无需密码）、Gmail（使用应用专用密码）、其他 IMAP/SMTP 账户，以及 Outlook（使用你自己的 Microsoft Entra 应用 ID）。发出的邮件会在发件箱等待 45 秒。一次性验证码和登录链接绝不会显示给模型。

开关: 读取 · 草稿 · 发送 · 整理

日历

你 Mac 上的日历，包括在“互联网账户”中添加的 Google 或 Outlook 日历。它无法邀请任何人。

开关: 读取 · 添加和修改（可撤销）

提醒事项

你 Mac 上的提醒事项。

开关: 读取 · 添加和修改（可撤销）

Mac 应用

备忘录、访达、Word、Excel、PowerPoint、音乐、照片、Safari、Chrome、通讯录、信息以及其他支持脚本的应用，无需点击屏幕。

开关: 每个应用一个开关

快捷指令

列出你的 Apple 快捷指令，并运行你指定的那一个。

开关: 每次运行前都会询问

桌面

读取应用窗口，经你允许后可以点击和输入。终端、密码管理器和系统设置始终禁止操作。

开关: 读取 · 控制

定时任务

在对话中设置、在 Vunemi 打开时按时运行的任务。绝不会发送、删除或付款。

开关: 设置与管理

自定义连接

通过命令或地址添加任意 MCP 服务器。它的密钥保存在保险库中。

开关: 每个连接一个开关

安全与掌控

权限级别

从“观察并建议”到“自主执行”共四种预设，另外还可按操作类型分别设置。涉及资金的操作始终关闭。

保险库

工具使用的密钥会用你 Mac 钥匙串中的密钥加密。模型只能看到名称。

活动日志

助理做过的每件事都保存在你的 Mac 上，并可撤销。

由 Vunemi 创建

它写的文件、保存的草稿、添加的日程和下载的文件，都可以“打开”或“在访达中显示”。

发件箱

等待发送的消息，以及每条消息的处理结果。

应用锁

用触控 ID 或 Mac 密码锁定 Vunemi。

你的数据，你做主

可以忘记单个会话、单条笔记或全部内容。记忆中的笔记永远不会授予权限，来自网页、邮件或文件的文字也永远不会成为笔记。

Vunemi 绝不会做的事

无论权限级别如何。遇到这些步骤，它都会停下来交给你。

  • 输入密码、银行卡号、账号或证件号码
  • 破解验证码（CAPTCHA）
  • 支付任何款项
  • 永久删除任何内容

在你的 Mac 上运行

使用 Vunemi 内置引擎，或你已有的模型服务器：LM Studio、Ollama 或 llama.cpp。也可以添加 Mac 上的 GGUF 文件。

11 种语言

中文、英语、土耳其语、德语、法语、西班牙语、意大利语、葡萄牙语、俄语、日语和韩语。

须知

  • 效果取决于模型和你的 Mac。小模型在复杂任务上更容易出错。
  • 适用于搭载 Apple 芯片、运行 macOS 14 或更高版本的 Mac。
  • 任务（包括定时任务）只在 Vunemi 打开时运行。
  • 应用已签名，但尚未经过 Apple 公证。首次打开时，你可能需要在“系统设置 › 隐私与安全性”中点按“仍要打开”。
