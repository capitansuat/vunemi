Mac 上的个人助理

Vunemi 的全部功能

详细了解 Vunemi 0.2.1：如何与它协作、它能连接什么，以及你如何保持掌控。

轻松处理邮件

找出等你回复的邮件，总结往来内容，并起草回复。支持 Mac 上“邮件”App 中的账户、Gmail、Outlook 和其他 IMAP 账户，未经你同意绝不发送。

安排好一天

读取你的日历和提醒事项，包括添加到 Mac 上的 Google 或 Outlook 日历，经你同意后添加日程或待办。

我明天的日程有哪些？

查找和整理文件

在桌面、文稿和下载文件夹中搜索，阅读文档，经你同意后移动或重命名文件。每项改动都可以撤销。

找出桌面上的发票，放到一个文件夹里。

上网查资料

在 Vunemi 内置的浏览器中打开网页，与你自己的浏览器分开。它会阅读、比较、填写表单，你随时可以点“接管控制”。

使用 Mac 应用

可配合备忘录、Excel、Word、PowerPoint、访达、通讯录、信息等应用工作，无需在屏幕上到处点击。每个应用都有单独的开关。

汇总这张 Excel 表里的支出。

说话代替打字

用在 Mac 上运行的语音模型听写：你说话，文字就会出现。在语音对话中，Vunemi 会用 Mac 自带的声音朗读回答，你可以随时开口打断。

给我看看今天的会议。

定时任务

让它每天早上做一份汇总，或每周检查一次。定时任务在 Vunemi 打开时运行，绝不会发送、删除或付款。

每天早上 9 点汇总我的日历。

给它看图片

附上截图或照片。能看懂图片的模型会描述内容；换成其他模型，Vunemi 也能在你的 Mac 上读出图中的文字。

记住你说过的话

告诉它你喜欢的工作方式，或谁是谁；经你同意后，它会用你的原话记下来。每个回答都会显示它收到了哪些笔记；你可以在设置中编辑或删除。

记住：我要 PDF 格式的报告。

录制会议

点击“录制”以采集麦克风和 Mac 声音。Vunemi 在此 Mac 上生成文字记录和摘要；摘要完成后将音频移入废纸篓。需要 macOS 14.2 或更高版本。

带入之前的工作

输入 @，选择之前的会话或会议。其中的提问和回答，或会议的摘要，会随消息一起发送；每条消息最多五个。

制作文档，编辑照片和视频

借助需要时再下载的扩展，Vunemi 可以撰写 Word 和 PDF 文档，制作带公式和图表的 Excel 工作簿，制作 PowerPoint 演示文稿，合并和拆分 PDF，编辑照片，剪辑短视频。每个结果都是一个新文件。

与 Vunemi 协作

先看计划

遇到需要多个步骤的任务，Vunemi 可以先给出计划。你可以开始执行、编辑步骤或取消。

确认卡片

每项改动都会以卡片形式呈现，写明会发生什么、在哪里、涉及谁。

排队或插队

任务运行时可以输入下一个请求。它会排队等候，你也可以中断当前任务，让它马上执行。

紧急停止

按 ⌘⇧Esc 可停止正在运行的任务，即使 Vunemi 已锁定也有效。

从中断处继续

如果 Vunemi 在任务中途关闭，它会告诉你进行到哪一步并提议继续；遇到会改动或发送内容的步骤，都会先问你。

项目

把一个文件夹设为项目：Vunemi 会把这项工作的文件放在那里，每项改动都可以撤销。

记忆

来自你原话的笔记，只有经你同意才会保存。每个任务只会收到与之相关的笔记，回答会说明收到了几条。

带入之前的工作

输入 @，选择之前的会话或会议。其中的提问和回答，或会议的摘要，会随消息一起发送；每条消息最多五个。

需要处理

所有会话中等待授权、等待你回复或等待检查的任务，都在一个列表里。选中一个就会打开那个任务，不会有事情悄悄停在旧会话里。看过之后可以把任务标为已看过；超过 7 天的检查项会自动从列表中移除，任务中再有新动静时会重新出现。

询问所选内容

选中回答中的一部分（最多 2,000 个字符），就它提问。引用会随问题一起发送，你不必复制，也不必解释指的是哪一部分。

任务进度

任务会显示它的步骤、生成了什么，以及每个结果是否经过检查。凡是 Vunemi 能读回的结果，例如已保存的草稿或已添加的日程，它都会检查；无法检查的会被标记出来，由你查看。

连接

每个连接在你打开之前都是关闭的。关闭的连接对模型不可见，其工具根本无法调用。很多连接对“读取”和“修改”设有单独的开关。

文件

只限你的桌面、文稿和下载文件夹。移动文件时会保留备份，绝不会覆盖已经存在的文件。

开关: 读取 · 写入（可撤销；删除的内容进入废纸篓）· 转换（图片、音频、文档）

浏览器

Vunemi 窗口中的浏览器，与你的 Chrome 或 Safari 分开。登录一次即可保持登录；随时可以接管控制。

开关: 读取网页 · 点击和输入

航班和酒店

在 Google Flights 和 Trivago 搜索，并以卡片展示结果。选择一张卡片即可在对话旁打开对应报价。你的航线或目的地、日期和人数会发送给 Google 或 Trivago。Vunemi 不会预订或付款。

开关: Google Flights · Trivago

邮件

Mac 上“邮件”App 中的账户（无需密码）、Gmail（使用应用专用密码）、其他 IMAP/SMTP 账户，以及 Outlook（使用你自己的 Microsoft Entra 应用 ID）。发出的邮件会在发件箱等待 45 秒。一次性验证码和登录链接绝不会显示给模型。

开关: 读取 · 草稿 · 发送 · 整理

日历

你 Mac 上的日历，包括在“互联网账户”中添加的 Google 或 Outlook 日历。它无法邀请任何人。

开关: 读取 · 添加和修改（可撤销）

提醒事项

你 Mac 上的提醒事项。

开关: 读取 · 添加和修改（可撤销）

Mac 应用

备忘录、访达、Word、Excel、PowerPoint、音乐、照片、Safari、Chrome、通讯录、信息以及其他支持脚本的应用，无需点击屏幕。

开关: 每个应用一个开关

快捷指令

列出你的 Apple 快捷指令，并运行你指定的那一个。

开关: 每次运行前都会询问

桌面

读取应用窗口，经你允许后可以点击和输入。在允许的应用中，Vunemi 还能在后台工作：按下按钮、修改字段、从菜单中选择或滚动，而不把窗口调到前台，你不必在它工作时停下手头的事。某个操作无法在后台完成时，不会发送任何内容。终端、密码管理器和系统设置始终禁止操作。

开关: 读取 · 控制

定时任务

在对话中设置、在 Vunemi 打开时按时运行的任务。绝不会发送、删除或付款。定时应用操作更进一步：在你批准的 24 小时内最多四个时间点，Vunemi 修改你打开着的文档，每次都会保留备份并检查结果，而且只在你离开键盘时运行。在此版本中，它会向 TextEdit 文档追加固定文字。

开关: 设置与管理

历史记录

当请求涉及以前的会话或已录制的会议时找到它。每次请求只附上最相关的几项的名称、日期和一行说明；Vunemi 只在需要时阅读其中一项。任何内容都不会离开你的 Mac。

开关: 查找和阅读

自定义连接

通过命令或地址添加任意 MCP 服务器。它的密钥保存在保险库中。

开关: 每个连接一个开关

扩展

需要时再添加的额外能力。每一项都是独立的程序：Vunemi 测试时所用的那份副本会从 Vunemi 自己的发布页面下载一次，并在安装前经过校验。它们在这台 Mac 上运行，无法访问网络，只能看到 Vunemi 交给它们的文件。 这些程序是 ArtCraft 团队的 Craft 应用，以 MIT 或 Apache-2.0 许可开源。它们还很新：结果可能与 Word、Excel 或 PowerPoint 不同。 Vunemi 更新时，你已安装的扩展也会随之更新；新版本通过校验之前，旧副本会保留。

即使没有扩展，Vunemi 也能读取 Word 和 PDF 文档，在不同格式之间转换文件；如果你的 Mac 上装有 Word、Excel 或 PowerPoint，它还能通过这些应用工作。扩展更进一步：Vunemi 自己生成文件，不需要 Office。表格里的合计是由电子表格程序计算的真正公式，而不是模型算出来的数字；演示文稿有真正的幻灯片和图表；照片和视频可以编辑，而不只是转换格式。以前 Vunemi 只能使用每个程序中几个固定的工具；现在它可以使用程序支持的全部功能，例如电子表格中的数据透视表或幻灯片的版式。工具会生成一个新文件，你交给它的文件保持原样。只有在你要求时，Vunemi 才会直接修改 Word、Excel 或 PowerPoint 文件：它会先在旁边保留一份备份，如果文件在你批准后发生了变化，就会停止。

文档

把报告、信件和笔记写成 Word 或 PDF 文件，带标题、列表和表格，并按你所在的地区使用 A4 或 Letter 纸张。还能把已有文档转换成其他格式，例如从 Word 转成 PDF。还能修改已有 Word 文档中的文字，例如日期、价格或姓名：修改写入一份保留原有格式的副本，小小的改动不必再把整个文件重写一遍。如果你要求，它也可以直接修改你的 Word 文件，修改前先在旁边保留一份备份。新文档中的表格有清晰的表头、舒适的行距和右对齐的数字。

电子表格

根据你给的数字制作 Excel 工作簿。合计、平均值和百分比都写成公式并由程序计算：以后在 Excel 里改动一个数字，合计会随之更新。还可以添加柱形图、条形图、折线图或饼图。它还能修改你已有的工作簿：添加工作表、写入公式或创建数据透视表。新表格有清晰的表头和对齐的数字，保留你给出的精度，不会自行猜测货币。

演示文稿

逐张制作 PowerPoint 演示文稿：标题页、章节标题、只有几行短句的幻灯片、图表和演讲者备注，可从八种主题中选用一种。还能读取已有的演示文稿并生成修改后的副本：修改某张幻灯片的文字、删除一张幻灯片、在你指定的幻灯片之后添加新的一张。它还能更改版式，并让文字适应文本框。

PDF 工具

把多个 PDF 合并成一个，把选定的页面提取到新文件，旋转页面，用图片生成 PDF，列出并填写表单字段。不会打开受密码保护的 PDF。

绘图

绘制海报、卡片、标志或示意图，并保存为 PNG、PDF 或 SVG。SVG 中的形状和文字仍可编辑，你可以在绘图软件中继续修改。由模型描述图形、程序负责渲染，所以效果取决于模型。

照片编辑

把图片裁剪成 1:1 或 16:9 等比例，旋转、翻转和调整大小，自动校正色调，调整亮度、对比度和饱和度，锐化或模糊，并保存为 JPEG、PNG、WebP 或 TIFF。可以读取 iPhone 的 HEIC 照片。不能移除物体或背景。背后的程序是开源图像编辑器 PhotoCraft。

视频剪辑

按你给的顺序把片段拼接起来，并对每个片段进行裁剪。可以添加标题、烧录进画面的字幕、音量较低的背景音乐和片段之间的淡入淡出，然后导出最长 30 分钟的 MP4。背后的程序是开源视频编辑器 FilmCraft。

安全与掌控

权限级别

从“观察并建议”到“自主执行”共四种预设，另外还可按操作类型分别设置。涉及资金的操作始终关闭。

保险库

工具使用的密钥会用你 Mac 钥匙串中的密钥加密。模型只能看到名称。

活动日志

助理做过的每件事都保存在你的 Mac 上，并可撤销。

由 Vunemi 创建

它写的文件、保存的草稿、添加的日程和下载的文件，都可以“打开”或“在访达中显示”。

发件箱

等待发送的消息，以及每条消息的处理结果。

应用锁

用触控 ID 或 Mac 密码锁定 Vunemi。

你的数据，你做主

可以忘记单个会话、单条笔记或全部内容。记忆中的笔记永远不会授予权限，来自网页、邮件或文件的文字也永远不会成为笔记。

本次运行的权限

当 Vunemi 请求读取文件或查看窗口时，你可以只允许一次，或在任务剩余期间允许最多 8 次，而不必逐次批准。文件一旦变化就需要新的权限，你可以随时撤销任何权限，而且权限不会延续到定时任务。

不确定就不重复

如果 Vunemi 无法判断某个操作是否生效，就不会再做一次。任务会被标记为“结果不确定”，等你检查，即使重新启动后也是如此。

Vunemi 绝不会做的事

无论权限级别如何。遇到这些步骤，它都会停下来交给你。

  • 输入密码、银行卡号、账号或证件号码
  • 破解验证码（CAPTCHA）
  • 支付任何款项
  • 永久删除任何内容

在你的 Mac 上运行

使用 Vunemi 内置引擎，或你已有的模型服务器：LM Studio、Ollama 或 llama.cpp。也可以添加 Mac 上的 GGUF 文件。

11 种语言

中文、英语、土耳其语、德语、法语、西班牙语、意大利语、葡萄牙语、俄语、日语和韩语。

须知

  • 效果取决于模型和你的 Mac。小模型在复杂任务上更容易出错。
  • 适用于搭载 Apple 芯片、运行 macOS 14 或更高版本的 Mac。
  • 任务（包括定时任务）只在 Vunemi 打开时运行。
  • 应用已签名，但尚未经过 Apple 公证。首次打开时，你可能需要在“系统设置 › 隐私与安全性”中点按“仍要打开”。
