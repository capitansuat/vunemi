Nouveautés de cette version · 0.5.1

  • Vunemi 0.5.1 sort le même jour pour Mac, Windows et Linux, à partir du même code. Désormais, chaque nouvelle fonction arrive sur les trois, sauf ce que seul un Mac possède.
  • « Autoriser cette fois seulement » sur une carte exécute désormais un outil désactivé pour ce seul appel, comme annoncé ; avant, l’appel échouait. L’outil reste désactivé ensuite.
  • Un chemin qui commence par Documents, Desktop ou Downloads mène désormais à ce dossier de votre dossier personnel, et non à un nouveau dossier du même nom sur le Bureau. Un fichier d’un dossier caché de votre dossier personnel reste refusé, quel que soit le chemin.
  • Sous Windows et Linux, Vunemi déplace désormais des fichiers, jamais par-dessus un autre ; Windows reçoit la dictée et Linux lit les réponses à voix haute. La page de téléchargement dit ce qui marche où.
!

Si macOS ne peut pas vérifier le téléchargement

Vunemi est signé, mais cette version n’a pas encore été notarisée par Apple. macOS peut bloquer l’image disque. Cet avertissement ne prouve pas que le fichier est sûr.

Ne poursuivez que si vous avez téléchargé cette version via le lien ci-dessus et comparé son SHA-256 à la valeur indiquée plus bas.

Si vous faites confiance au fichier, voici comment l’ouvrir :

  1. Essayez d’ouvrir le fichier. Dans l’alerte, choisissez « OK ».
  2. Ouvrez Réglages Système › Confidentialité et sécurité et faites défiler jusqu’à la section Sécurité.
  3. À côté du message indiquant que le fichier a été bloqué, cliquez sur « Ouvrir quand même ». Le bouton n’apparaît qu’après une tentative d’ouverture ; s’il a disparu, réessayez.
  4. macOS demande une nouvelle confirmation et peut demander le mot de passe de votre Mac ou Touch ID. Confirmez vous-même.

Pas de bouton « Ouvrir quand même » ? Dans la même section Sécurité, vérifiez d’où macOS autorise les apps : si seul l’App Store est sélectionné, choisissez l’App Store et les développeurs identifiés, puis réessayez d’ouvrir le fichier. macOS peut aussi bloquer Vunemi lui-même à sa première ouverture depuis Applications ; les mêmes étapes s’appliquent.

En cas de doute, n’ouvrez pas le fichier et contactez l’assistance.

Consignes d’Apple ↗

Installation

  1. Ouvrez l'image disque téléchargée.
  2. Faites glisser Vunemi dans le dossier Applications.
  3. Ouvrez Vunemi depuis Applications. Si macOS indique qu'il ne peut pas être ouvert, allez dans Réglages Système › Confidentialité et sécurité et cliquez sur Ouvrir quand même.
  4. Choisissez un modèle sur le premier écran. Vunemi en propose un adapté à votre Mac.

Il vous faut

  • Un Mac avec puce Apple (M1 ou ultérieur)
  • macOS 14 ou ultérieur
  • De la place pour un modèle : l'app affiche la taille de chaque modèle avant le téléchargement

Mise à jour

À partir de 0.1.8, Vunemi vous prévient quand une nouvelle version sort et se met à jour quand vous appuyez sur Mettre à jour. Depuis une version plus ancienne, téléchargez une fois la nouvelle image disque et faites glisser Vunemi dans Applications en choisissant Remplacer.

Si macOS demande votre mot de passe à l'ouverture de Vunemi

Vunemi conserve la clé de son coffre dans le trousseau de votre Mac. Comme Vunemi n'est pas encore signé avec une identité de développeur Apple, macOS reconnaît la partie qui lit cette clé à son code exact ; après une mise à jour qui la modifie, macOS demande une fois votre mot de passe de session. Saisissez-le et choisissez « Toujours autoriser » : macOS ne le redemandera que lorsqu'une mise à jour ultérieure modifiera cette partie. « Autoriser » seul ne vaut qu'une fois, et macOS redemandera au prochain lancement. Cette demande vient de macOS ; Vunemi ne voit jamais votre mot de passe.

Installation

  1. Choisissez les fichiers pour votre ordinateur : x64 pour la plupart des PC, arm64 pour les ordinateurs ARM. Pour vérifier, lancez uname -m : x86_64 signifie x64, aarch64 signifie arm64.
  2. Ubuntu et Debian : téléchargez le .deb et installez-le avec sudo apt install suivi de son chemin, par exemple sudo apt install ./Vunemi-0.5.1-linux-amd64.deb. Les paquets dont il a besoin sont installés avec lui.
  3. Autres distributions : téléchargez l’AppImage, rendez-la exécutable avec chmod +x et ouvrez-la. Gardez-la dans un dossier où vous pouvez écrire, comme ~/Applications, pour qu’elle puisse se mettre à jour toute seule.

L’AppImage se met à jour toute seule : quand une nouvelle version sort, elle l’indique dans la barre latérale et dans Réglages › Mises à jour ; cliquez sur Mettre à jour. Avant d’utiliser le fichier, elle le vérifie avec la signature du développeur. Le .deb ne se met pas à jour tout seul, car le remplacer demanderait votre mot de passe administrateur : il vous signale la nouvelle version et ouvre cette page, où vous la téléchargez comme avant.

Il vous faut

  • Un ordinateur 64 bits : x64 (la plupart des PC) ou ARM (arm64)
  • Ubuntu 22.04 ou ultérieur, Debian 12 ou ultérieur, ou une autre distribution avec glibc 2.35 ou ultérieure

Sous Linux, vous avez la discussion et les tâches avec les fichiers de votre ordinateur, les modèles locaux via le moteur intégré, Ollama ou LM Studio, la dictée et la discussion vocale, le déplacement de fichiers et le coffre. La discussion vocale lit les réponses à voix haute avec espeak-ng, fourni avec l’app parce que Linux n’a pas de voix présente sur tous les ordinateurs : il parle les onze langues mais sonne robotique, et il ne lit le japonais qu’en kana, donc les kanji ne sont pas bien lus ; sans lui, vous lisez les réponses à l’écran. Le déplacement ne déplace que le fichier que vous avez approuvé et ne remplace jamais un autre fichier ; sans lui, Vunemi lit, écrit et copie toujours les fichiers. Le coffre a besoin de GNOME Keyring ou de KWallet ; sans eux, il reste verrouillé et tout le reste fonctionne.

Pas encore sous Linux : piloter les apps et le bureau, les outils d’archives, l’enregistrement des réunions, les tâches planifiées, les modules et le verrouillage de l’app. Raccourcis, Calendrier et Apple Mail sont des apps Mac et restent sur Mac. Quelques textes mentionnent encore le Mac ou le Finder.

Windows vous avertit la première fois

Le programme d'installation n'est pas signé avec un certificat de signature de code payant : Microsoft Defender SmartScreen indique donc qu'il ne connaît pas l'éditeur. L'avertissement peut revenir lors d'une mise à jour.

  1. Ouvrez le programme d'installation.
  2. Si Windows affiche « Windows a protégé votre ordinateur », choisissez Informations complémentaires.
  3. Vérifiez que l'app est Vunemi-Setup, puis choisissez Exécuter quand même.

Les mises à jour ne dépendent pas de SmartScreen : avant de lancer un nouveau programme d'installation, Vunemi le vérifie avec une signature faite avec la clé du développeur. Un fichier modifié sur ce site ou sur GitHub ne peut pas être installé.

Installer

  1. Choisissez le programme d'installation de votre ordinateur : x64 pour la plupart des PC, arm64 pour Windows sur ARM. Pour vérifier, ouvrez Paramètres › Système › Informations système et regardez Type du système.
  2. Ouvrez-le. Il s'installe pour votre compte seulement et ne demande aucun mot de passe d'administrateur.
  3. Vunemi s'ouvre à la fin. Vous le retrouvez ensuite dans le menu Démarrer.

Vunemi pour Windows se met à jour tout seul : quand une nouvelle version sort, il l'indique dans la barre latérale et dans Réglages › Mises à jour ; cliquez sur Mettre à jour.

Il vous faut

  • Windows 11 sur un ordinateur x64 ou ARM (arm64)
  • Environ 500 Mo pour l'app, plus de la place pour un modèle

Sous Windows, vous avez la discussion et les tâches avec les fichiers des dossiers que vous ouvrez, les modèles locaux avec le moteur intégré, Ollama ou LM Studio, la dictée et la discussion vocale, le déplacement de fichiers, le coffre (Windows garde sa clé pour votre compte), la Corbeille et les mises à jour depuis l'app. La dictée transforme ce que vous dites en texte sur votre ordinateur, sans rien envoyer ailleurs ; la discussion vocale lit les réponses avec les voix de Windows. Sans elles, vous tapez et lisez comme avant. Le déplacement ne déplace que le fichier que vous avez approuvé et ne remplace jamais un autre fichier ; sans lui, Vunemi lit, écrit et copie toujours les fichiers.

Pas encore sous Windows : piloter les apps et le bureau, les outils d'archives, l'enregistrement des réunions, les tâches planifiées, les modules et le verrouillage de l'app. Raccourcis, Calendrier et Apple Mail sont des apps Mac et restent sur Mac.
